# TANK DUO — танчики онлайн на двох

Аркадна гра з оригінальною піксельною графікою, натхненна класичними «Танчиками» на Dendy.

## Що є в грі

- Кооперативна гра з другом через інтернет: один створює кімнату, інший вводить 6-символьний код.
- Соло-режим без підключення друга.
- Танки, постріли, вороги з автоматичною поведінкою, кілька хвиль з поступовим ускладненням.
- Цегляні стіни, які руйнуються; непрохідна сталь і вода; кущі для маскування.
- База, яку потрібно захищати, життя гравців, очки команди, звукові ефекти.
- Клавіатура (WASD або стрілки + пробіл), сенсорне керування на телефонах.

## Як зіграти вдвох (найпростіший безкоштовний спосіб)

1. Створіть безкоштовний акаунт на https://github.com (якщо його ще немає).
2. Створіть **Public** репозиторій з назвою `tank-duo`.
3. Додайте файл `index.html` з цього архіву в **корінь** репозиторію (Add file → Upload files → Commit changes).
4. Відкрийте **Settings → Pages → Build and deployment**.
5. Встановіть **Source: Deploy from a branch**, **Branch: main**, **Folder: / (root)** і натисніть **Save**.
6. Коли GitHub опублікує сайт, він буде доступний за адресою `https://ВАШ-ЛОГІН.github.io/tank-duo/` (приклад адреси, замініть логін).
7. Відкрийте сайт, натисніть **«Створити кімнату для друга»**, потім **«Скопіювати посилання»**.
8. Надішліть посилання другу. Він відкриває його і натискає **«Увійти в кімнату»**. Після цього гра розпочнеться для вас обох.

Необхідна відкрита вкладка браузера в обох гравців. Хост (той, хто створив кімнату) керує симуляцією; друг отримує її стан через WebRTC.

## Як перевірити на своєму комп’ютері

Двічі клацніть `index.html` — відкриється гра в браузері. Натисніть **«Грати самому»**. Для зручного запрошення за посиланням спочатку опублікуйте файл на GitHub Pages. Якщо обидва гравці відкривають HTML локально, вони можуть спробувати підключитися за кодом кімнати, але пряме з'єднання залежить від налаштувань браузера і мережі.

## Важливо

- Сама гра не має власного платного сервера або ключів API.
- Онлайн-з’єднання використовує **PeerJS Cloud** для пошуку другого гравця і **WebRTC DataChannel** для прямої передачі даних між браузерами.
- На деяких мережах (корпоративний фаєрвол, симетричний NAT, блокування WebRTC) пряме P2P-з’єднання може не встановитися: без окремого TURN-сервера робота на всіх мережах не гарантується.
- PeerJS Cloud — спільний безкоштовний сервіс без гарантії доступності для кожного підключення; для гри з другом зазвичай достатньо.
- Залежність PeerJS завантажується з CDN (`unpkg.com`), тому для створення онлайн-кімнати потрібне підключення до інтернету.
- Реєстрація на GitHub потрібна лише людині, яка розміщує сайт; другові акаунт не потрібен.

Технічні джерела: https://peerjs.com/server/cloud та https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages
